# SQL Course Notes

Personal knowledge base created while studying SQL.

The purpose of this repository is not to transcribe the entire course, but to document the SQL concepts, commands, syntax, examples, and security topics that are useful for future reference and practice.

---

## Course Topics

This repository covers topics such as:

- SQL fundamentals
- `SELECT`
- `DISTINCT`
- `WHERE`
- `ORDER BY`
- Logical and comparison operators
- `LIKE`, `IN`, and `BETWEEN`
- `INSERT`
- `UPDATE`
- `DELETE`
- Aggregate functions
- SQL aliases
- SQL joins
- `UNION`
- `GROUP BY`
- `HAVING`
- Subqueries
- `EXISTS`
- `ANY` and `ALL`
- Databases and tables
- SQL data types
- Constraints
- Primary and foreign keys
- Indexes
- Auto increment
- Dates
- Views
- Stored procedures
- SQL Injection
- SQL parameters
- Prepared statements

## Learning Approach

For each topic, the notes will focus on:

- What the SQL command or concept does
- Basic syntax
- Practical examples
- Important operators and options
- Common mistakes
- Quick-reference information
- Security considerations when relevant

The goal is to build a practical SQL reference that can be used for:

```text
Learning
Practice
Assessments
Development
Cybersecurity
Future reference
```
